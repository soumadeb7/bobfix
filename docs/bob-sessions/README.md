# Bob Session Evidence

The hackathon requires IBM Bob IDE task-session summary screenshots as
evidence that Bob actually performed the workflow described in
`BOB_WORKFLOW.md`.

**These screenshots must be captured by you, from real Bob sessions.**
Nothing in this repository fabricates or claims a Bob session that did not
happen.

## Checklist

- [ ] Repository analysis session (Step 1)
- [ ] Parallel investigation session (Step 2)
- [ ] Test-generation session (Step 3)
- [ ] Failure diagnosis session (Step 4)
- [ ] Bug-fixing session (Step 5)
- [ ] Final verification session (Step 6)

## Where to save them

Save each screenshot in this folder (`docs/bob-sessions/`), named to match
the step, e.g.:

```
docs/bob-sessions/01-repository-analysis.png
docs/bob-sessions/02-parallel-investigation.png
docs/bob-sessions/03-test-generation.png
docs/bob-sessions/04-failure-diagnosis.png
docs/bob-sessions/05-bug-fixing.png
docs/bob-sessions/06-final-verification.png
```

Reference them from the main `README.md` once captured.
