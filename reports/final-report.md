## 1. Bugs Discovered

10 bugs were identified across three source modules through static analysis and
confirmed by failing tests. All bugs were pre-seeded and documented in
`dataset/bug_cases.json`.

| ID | Priority | Module | Function | Scenario |
|---|---|---|---|---|
| BUG-001 | High | `calculator.js` | `calculateDiscount` | Discount > 100% returns a negative price |
| BUG-002 | Medium | `calculator.js` | `calculateDiscount` | Negative discount silently increases the price |
| BUG-003 | High | `calculator.js` | `calculateTotal` | Zero or negative quantity returns 0 or a negative total |
| BUG-004 | Medium | `calculator.js` | `calculateTax` | `Math.floor` truncates instead of rounding — undercounts tax by up to 1¢ |
| BUG-005 | Medium | `user.js` | `validateEmail` | Regex accepts addresses with no domain suffix (e.g. `a@b`) |
| BUG-006 | High | `user.js` | `isAdult` | `age > 18` (strict) — age exactly 18 is incorrectly rejected |
| BUG-007 | Medium | `user.js` | `createUser` | No input validation — empty name or malformed email builds an invalid record |
| BUG-008 | High | `order.js` | `calculateOrderTotal` | `item.quantity` is ignored — multi-unit lines are undercounted |
| BUG-009 | Medium | `order.js` | `validateOrder` | Empty array `[]` passes validation — an order with no items is accepted |
| BUG-010 | Medium | `order.js` | `applyDiscount` | Discount > 100% returns a negative order total |

---

## 2. Bugs Fixed

All 10 bugs were fixed with minimal, targeted changes. No existing intended
behaviour was altered.

### `src/calculator.js`

| Bug | Change |
|---|---|
| BUG-001 / BUG-002 | Added `if (discount < 0 \|\| discount > 100) throw` guard in `calculateDiscount` |
| BUG-003 | Added `if (quantity <= 0) throw` guard in `calculateTotal` |
| BUG-004 | Replaced `Math.floor(tax * 100) / 100` with `Math.round(tax * 100) / 100` in `calculateTax` |

### `src/user.js`

| Bug | Change |
|---|---|
| BUG-005 | Tightened `validateEmail` regex from `/^[^\s@]+@[^\s@]+$/` to `/^[^\s@]+@[^\s@]+\.[^\s@]+$/` |
| BUG-006 | Changed `isAdult` comparison from `age > 18` to `age >= 18` |
| BUG-007 | Added `!name` and `!validateEmail(email)` guards in `createUser` before constructing the record |

### `src/order.js`

| Bug | Change |
|---|---|
| BUG-008 | Changed `total += item.price` to `total += item.price * item.quantity` in `calculateOrderTotal` |
| BUG-009 | Added `if (items.length === 0) return false` in `validateOrder` |
| BUG-010 | Added `if (discount < 0 \|\| discount > 100) throw` guard in `applyDiscount` |
